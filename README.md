1. Download the Amazon (Electro) dataset from **https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/categoryFiles/Electronics.json.gz** and **https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/metaFiles2/meta_Electronics.json.gz**, extract them to the **/ATJT/amazon** directory.

2. Run **python run.py** in the command line.
